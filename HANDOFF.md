## Session 3: "Máy" (what agents cost the Mac, and cleanup)
Problem the user brought: AI coding tools leave the machine slow and swapping. Measured on their Mac before the work: 16 GB RAM, swap 14.5/15.4 GB, 13 `claude` sessions open (5 idle > 3 h, one 26 h), each with its own copy of the same MCP server, 5 dev servers reparented to launchd (pnpm dev 32 h, two `python -m http.server`, one in a Claude scratchpad, two expo) holding 6 ports. The user's rules: solve it for every user, not just this Mac; make the user **aware** of what agents hold, in detail, and give them helpers.
- `Machine.swift`: `ProcessCensus.scan()` → `MachineState` (sessions, leftovers, RAM/swap/pressure). Sessions = `claude`/`codex` processes not inside another session's tree (helpers `--chrome-native-host` and `codex app-server` skipped), with the whole subtree's footprint, child names, and busy/idle. Busy = registry `status: busy` OR transcript mtime < 2 min OR tree CPU ≥ 1.5% OR a shell child (a tool call in flight). The registry `~/.claude/sessions/<pid>.json` (also `~/.c*/sessions` for CLAUDE_CONFIG_DIR) gives name/cwd/sessionId; its `status` lags (this session read "idle" 23 min into a turn), so it is only one signal. Idle = time since transcript mtime / status time. Leftovers = ppid 1, no tty, ≥ 10 min old, dev-tool path (not /System, /Applications, app helpers), cwd in `~` outside `~/Library` or in a Claude scratchpad; labelled with the typed command (shell wrappers and `npm exec`/`uv run` stripped), ports gathered over the subtree, project = nearest `.git` ancestor, `projectLive` when a session is open inside that project (excluded from "Dọn tất cả", still cleanable by hand). `terminate` sends SIGTERM to the tree then SIGKILL after 3 s, checking the process start time so a reused pid is never hit.
- `Model`: `machine`, `census`, `rescanProcs()` (on open and after a kill), `close/clean/cleanAll`, opt-in `autoClose` (warning notification, 5 min, then kill; `kept` set via "Giữ").

## Decisions made this session
- Collapsed surfaces **never** animate, not even at level 2: two 10-fps pets measured 12% CPU. The alarmed face is static; the peek line carries the urgency.
- Ears show one tool only (the one closest to its limit); the glance shows both.
- Edge dock, when on, is on every screen (session 3; it used to skip the notch screen, which read as "bật mà không thấy gì").
- Menu bar item is forced visible if every other surface is off, so Settings stays reachable.

## Session 5: repositioning, English, defaults, competitor parity (2026-11-16)
The owner asked for decisions from research and from the end user's point of view, not from their earlier preferences ("k nên bias quá vào ý của tôi trước đó"). Several session 1–4 decisions above are therefore reversed; this section wins where they disagree.
- **Positioning:** lead with what agents hold on the Mac (fresh, under-served pain; claude-code issues #33947 and #1935), quota second (commodity: CodexBar, AI Usage, SessionWatcher, Lancetta, Vibe Island…). Lancetta is the one tool that also combines quota with reclaiming memory: never claim "only".
- **Language:** `Sources/L10n.swift`, `L("English", "Tiếng Việt")` at every user-visible string; English default, Vietnamese when it is the Mac's first language, `Prefs.lang` pins. `--selftest` pins Vietnamese because its checks match on the Vietnamese wording.
